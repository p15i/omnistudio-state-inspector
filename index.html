OmniStudio State Inspector

Privacy Policy

Information accessed

When you click “Query OmniScript State”, the extension searches the DOM of the currently inspected page for a matching OmniScript element and reads its state

How information is used

The inspected value is parsed and displayed as formatted JSON in the extension's Developer Tools panel. This processing takes place locally in the browser to provide the extension's stated functionality.

Collection, storage and sharing

The extension does not transmit inspected page content to the developer or third parties. It does not send telemetry or analytics, and it does not intentionally persist inspected state in extension storage.

Sensitive information

The inspected state may contain personal, confidential or other sensitive application information, depending on the page being inspected. Users should inspect only systems and data they are authorised to access and should take care when copying or sharing the output.

Changes and contact

This policy will be updated if the extension's information-handling practices change.

Privacy questions can be directed to email address on the extension's Chrome Web Store listing.
